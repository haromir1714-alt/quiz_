- 별도 3단계의 전체 재검수, 다른 검수자나 분야 전문가의 검토는 아직 수행하지 않았다.

- 링크와 본문 접근 가능성은 확인 시점 기준이며 앞으로의 변경·삭제까지 보장하지 않는다. 차단된 UNESCO 무형유산 원문을 읽었다고 보고하지 않는다.
