# 전체 200문제 재검수 결과 — 1.1.1

확인일: 2026-10-17. 재검수 대상은 1.1.0의 전체 200문제이며, 이전의 검증 완료 표시만으로 통과시키지 않았다.

## ① 재검수 범위와 결과

| 항목 | 결과 |
| --- | --- |
| 질문·정답·보기 3개·해설의 편집 검토 | 200문제 전체 |
| 실제 출처 재열람 | 서로 다른 URL 130개 전체 |
| 정답을 특정하는 원문 관계·정의·표·작품 정보 대조 | 전체 문항 검토 |
| 시대·장소·과학 조건, 오답의 동의어·포함 관계 검토 | 전체 문항 검토 |
| 중복·다른 문항의 직접 답 노출·보기 표현 검토 | 전체 문항 검토 |
| 사실 오류로 정답 사실을 교체한 문항 | 이번 검수에서 발견하지 못함 |
| 문장·조건·질문 방식 등을 수정한 문항 | 20개 |
| 질문을 정의형으로 재구성한 문항 | 위 20개 중 2개 |
| 제외·보류한 출제 문항 | 없음 |

열람 과정에서 검색 서비스의 일시적인 오류가 난 3개 URL은 재시도 후 원문을 열었다. 긴 역사 페이지에서 본문 일부만 반환된 경우에는 필요한 위치를 추가로 열어 성종과 경국대전, 갑신정변의 연도 등을 확인했다. 원문 열람에 성공했다는 사실과 그 원문의 문장 의미를 검토한 사실을 구분했다.

오답 배제는 해당 원문이 특정하는 사실·정의와 보기의 비동일성, 질문 조건을 대조한 편집 판단이다. 800개 보기 각각에 별도 문서를 확보한 것은 아니다. 같은 AI 도우미가 다시 검토했으며 외부 전문가·다른 사람의 독립 검수는 수행하지 않았다.

| art-050 | 동명의 다른 오페라와 구별하도록 해설에도 ‘1816년 작곡’ 조건을 유지 |

수정 전후는 `rereview-changes-1.1.1.json`, 전체 문항 검토 목록은 `review-matrix-1.1.1.json`에 있다. 질문 방식 변경에 맞춰 두 문항의 보기와 오답 판단도 갱신했다. 근거 사실 자체가 틀려서 교체한 것과 질문 방식을 바꾸면서 정답 표현이 바뀐 것을 구분한다.

모든 문항의 출처에 원문 검색어를 추가했다. 웹 도구가 붙이는 임시 행 번호 대신, 사용자가 브라우저의 Ctrl+F로 실제 단어를 찾을 수 있게 했다. 문서에는 원문에 실제로 표시되는 영어·한국어 검색어를 사용했다. 여러 출처가 있는 문항은 원문마다 적합한 검색어를 사용한다.

## ③ 최종 출제 가능 문제 수와 자동 검사

| 분야 | 검증 완료·출제 가능 |
| --- | ---: |
| 한국사 | 50 |
| 과학 | 50 |
| 지리 | 50 |
| 예술과 문화 | 50 |
| 합계 | 200 |

문제 ID 중복, 보기 4개, 보기 ID·내용 중복, 빈 질문·보기·해설, 정답 ID 대응, 출처 필수 정보, 검수 기록, 분야별 최소 3개 조건을 프로그램으로 검사했다. 오류 0개, 경고 0개이다. 이 검사는 원문의 의미나 사실의 진실성을 자동 증명하지 않는다.

기능 자동 테스트 45개, TypeScript 검사와 Vite 빌드가 통과했다. 보기 순서 24가지 × 보기 4개 × 200문제인 19,200가지 채점 경우를 포함한다. 1.0.0·1.1.0·1.1.1 기록을 보존하면서 버전별 순위를 분리하는 검사도 포함한다.

읽기용 HTML의 200개 질문·보기·정답·해설·출처 URL을 원본 JSON과 프로그램으로 대조해 일치함을 확인했다. HTML에는 스크립트·iframe·이미지가 없다. 이것은 실제 브라우저 시각 검사를 대신하지 않는다.

## ④ 확인 방법과 남아 있는 한계

1. 최신 ZIP을 모두 압축 푼다.
2. `knowledge-quiz/docs/question-bank.html`을 더블클릭해 Chrome 또는 Edge로 연다. 문서를 읽는 데에는 Node.js나 서버가 필요 없다.
3. 분야 링크로 이동하고 Ctrl+F로 문제 ID 또는 단어를 찾는다. 200문제의 정답과 해설이 모두 표시된다.
4. 출처를 클릭하고 새 탭에서 표시된 원문 검색어를 Ctrl+F로 찾는다. 출처 열람에는 인터넷이 필요하다.
5. 단순 목록은 같은 폴더의 `question-bank.md`, 실제 게임 데이터와 오답별 판단은 `src/data/question-bank.json`에서 확인한다.
6. 데이터 형식과 게임 기능을 다시 검사하려면 프로젝트 폴더에서 `npm run check`를 실행한다. 사실을 확인하려면 여전히 원문을 직접 대조해야 한다.

은행 버전은 1.1.1로 올렸다. 같은 브라우저·프로필·주소의 과거 1.0.0과 1.1.0 기록은 남으며 순위 화면의 버전 선택에서 구분한다. 읽기용 문서는 JSON을 옮긴 사본이므로 직접 데이터를 수정하면 `npm run export:questions`로 다시 생성한다. 이 명령은 사실을 승인하지 않는다.

이번 재검수에서 해결되지 않은 사실 충돌은 발견하지 못했다. 다만 외부 독립 검수, 실제 사용자 난이도 측정, 앞으로의 링크 유지와 사실 오류의 완전한 부재는 보장하지 않는다. 실제 Windows 실행·PC와 모바일 브라우저의 시각적 배치·브라우저 완전 종료 후 저장 유지 검사는 미실행이다. 직접 확인 절차는 `MANUAL-CHECKLIST.md`에 있다.
