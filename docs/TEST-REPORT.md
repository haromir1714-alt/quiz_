실제 앱 컴포넌트를 jsdom에 마운트하여 닉네임·시작·정답·오답·제출·해설·연결된 출처 URL·12문제 완료·분야 결과·순위·결과 재진입·다시 하기·삭제 확인/취소/Escape·키보드·문제 부족·저장 실패/재시도를 확인했습니다. 저장 실패 재시도는 같은 ID로 1개만 저장되는지 확인했습니다. HTML 모양 닉네임이 HTML 태그로 해석되지 않고 텍스트로 출력되는 것도 확인했습니다.

새로고침은 컴포넌트 재마운트로 모사했고, 저장소 재읽기·기록 유지를 확인했습니다. 이 결과가 실제 브라우저 프로세스 재시작이나 물리 디스크 저장 확인을 대신하지 않습니다.

기존 40문제의 질문·보기·정답·해설을 유지하고 원문 열람·재열람으로 검수한 160문제를 추가했습니다. 신규 근거 원문 88개와 문항별 추적 기록이 있습니다. 구조 검사는 사실의 참·거짓을 자동 판정하지 않습니다. 앱에서 질문·정답·해설·출처를 새로 생성하거나 번역하지 않습니다. 런타임 AI 호출·실시간 출제 생성·외부 폰트 요청은 없습니다. 게임 사용에 필요한 초기 앱 파일 요청 외에 문제 API를 요청하지 않습니다. 사용자가 출처를 누르면 해당 외부 사이트를 엽니다.

전체 재검수에서 출처 URL 130개를 다시 열었고 문장·조건을 수정한 20문제를 포함해 출제 가능 수량은 200개입니다. 읽기용 question-bank.html의 200개 질문·보기·정답·해설·출처 URL을 JSON과 대조하여 일치함을 확인했습니다. 이 HTML의 실제 브라우저 시각 검사는 미실행입니다.

현재 번들의 크기는 압축 전 약 853kB, gzip 약 128kB입니다. Vite가 500kB 초과 청크에 대한 권고 경고를 표시했지만 타입 검사와 빌드는 성공했습니다. 실제 저성능 모바일의 초기 로딩 속도는 측정하지 않았습니다.

## ② 발견하고 수정한 오류

- 초기 CSS의 불필요한 import가 빌드를 막아 제거했습니다. 최종 빌드는 통과했습니다.
- 프로젝트의 Node.js 조건을 테스트 의존성의 요구 버전까지 반영해 24.15.0 이상인 24 LTS 사용을 안내했습니다.
- 콘텐츠 검사 스크립트의 기본 경로를 실제 앱의 src/data/question-bank.json으로 맞췄습니다.
- 손상된 완료 날짜가 정상 날짜로 자동 보정되어 읽히지 않도록 UTC 형식과 날짜 왕복 비교를 보강했습니다.
- 테스트 초기 실패 두 건은 fieldset 상속 비활성화를 input.disabled 속성만으로 보던 검사와 중복 텍스트를 단일 요소로 찾던 검사 문제였습니다. 검사 기준을 바로잡고 키보드·비활성 동작을 재확인했습니다. 제품 버그를 고쳤다고 잘못 보고하지 않습니다.
- 확장 후 40개·분야별 10개를 기대하던 테스트를 200개·분야별 50개로 갱신했습니다. 잘못된 문제를 제외한 뒤 수량을 확인하는 검사는 실제 전체 수량에서 제외 수를 빼도록 변경했습니다.
- 신규 초안 예시 ID가 기존 ID와 충돌하지 않게 문서를 수정했습니다. 콘텐츠의 중의성 수정 내역은 확장 검수 보고서에 있습니다.

## ③ 미실행 항목

- 실제 PC 브라우저에서 전체 화면을 열어 눈으로 배치·색상·겹침을 보는 검사.
- 실제 모바일 기기의 터치·스크롤·렌더링과 모바일 크기에서의 시각적 검사.
- Windows에서 Node.js 설치, npm ci, CMD 실행과 종료.
- 실제 브라우저 새로고침·완전 종료 후 재시작·시크릿 모드·브라우저별 저장 정책.
- 실제 브라우저의 용량 부족·저장 차단 정책 전체 조합과 스크린리더 음성 출력.
- 실제 앱에서 링크를 클릭해 외부 원문이 새 창으로 열리는 과정. 링크 URL 대응은 자동 검사, 원문 내용은 콘텐츠 검수 단계에서 확인했습니다.
- 사용자 GitHub 저장소 인증·원격 연결·push.

현재 환경에 지정된 control-browser 도구가 없습니다. 적용되는 [Sites SKILL.md](skill://plugin_connector_1p_689987207de08191979cf68eca2941c6/sites/SKILL.md)는 “If `$control-browser` is unavailable, skip browser QA”라고 지시합니다. 이에 따라 별도 브라우저나 다른 제어 경로로 우회하지 않았고 프리뷰 서버를 실행하지 않았습니다. 실제 브라우저 테스트를 통과했다고 보고하지 않습니다. 사용자 확인 절차는 MANUAL-CHECKLIST.md에 있습니다.

## ④ 남아 있는 제한사항

- 진행 중 새로고침은 초기화됩니다. 완료 기록만 보존합니다.
- 저장소가 삭제되면 복구하지 못합니다. 다른 브라우저·프로필·주소·기기와 기록을 공유하지 않습니다.
- 사용자 기기의 저장 데이터와 시계는 조작할 수 있어 공식 경쟁용 순위 무결성은 보장하지 않습니다.
- 콘텐츠 검수는 공식 원문 대조와 동일 AI의 재검수입니다. 외부 전문가 검수, 난이도 실측, 미래의 링크 유지, 사실 오류 부재를 보장하지 않습니다.
- 실제 시각 검증 전이므로 모바일 배치·보조 기술·실제 브라우저별 차이가 남아 있을 수 있습니다. 사용자가 위 절차로 실행한 결과에 따라 보완이 필요할 수 있습니다.
