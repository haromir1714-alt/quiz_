# 3단계 문항별 재검수 기록

40개 문항의 원문을 다시 열고, 질문·정답·오답·해설·조건·시간 변동성·중복·보기 단서를 대조했다. 이전 검증 표시만으로 통과시키지 않았다.
표의 통과는 실제 재검수 판단이며 자동 구조 검사가 사실의 진실성을 증명한다는 뜻이 아니다.
