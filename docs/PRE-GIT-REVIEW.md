# Git 등록 전 점검 — 문제 은행 1.1.2

확인일: 2026-10-18. 사용자가 전달한 외부 사이트 검수 의견을 원문과 실제 코드에 대조해 반영했다. 해당 보고서의 ‘오류가 전혀 없다’는 표현을 보증으로 채택하거나, 확인하지 못한 외부 검수 절차를 독립 검수 완료로 기록하지 않았다.

## 반영한 수정

- art-028: 전자책 추출 원문에도 `fve dancers`가 그대로 표시됨을 다시 확인했다. `five dancers`를 검색어로 바꾸면 찾지 못할 수 있어 검색어를 실제 존재하는 `Cheoyongmu`로 변경하고 추출 표기 차이를 설명했다. 다섯 명이라는 정답은 유지했다.
- hist-021: 질문에서 이성계 이름을 빼고 고려 말 요동 정벌 도중 군대를 돌린 사건의 위치를 묻도록 정리했다. 정답 위화도는 유지했다.
- geo-006: 질문에서 네팔이라는 불필요한 국가 단서를 빼고 사가르마타 국립공원에 포함된 산을 물었다. 정답 에베레스트산은 유지했다.
- 문제 은행 버전은 1.1.2로 변경했다. 분야별 50개, 총 200개와 한 게임 12문제 규칙은 유지했다. 기존 완료 기록은 해당 버전에 남는다.
- 원본 JSON에서 전체 HTML·Markdown 문서를 다시 생성하고 내용 대응을 확인했다.

이번에 다시 연 출처는 위 세 수정에 연결된 원문 3개이다. 전체 200문제·130개 URL을 다시 열었던 검수는 2026-10-17의 `REREVIEW-1.1.1.md`에 기록되어 있다.

## 외부 의견 중 코드·내용 확인 후 유지한 사항

| 제안 | 판단 |
| --- | --- |
| hist-006과 hist-007의 힌트 공유 | 경주를 수도로 삼은 국가와 백제의 웅진 소재지는 다른 사실이다. 두 질문이 상대 정답을 직접 제시하지 않아 유지 |
| hist-019와 hist-021 | 이름이 등장하는 것만으로 건국 관계를 증명하는 것은 아니지만, 불필요한 이름을 제거해 간접 단서를 줄임 |
| geo-006과 geo-047 | 서로 다른 장소이므로 국가 일치만으로 직접 답 노출은 아니지만, 앞 질문에서 국가를 제거 |
| art-047과 art-048 | 작곡가와 특정 곡의 악기는 서로 다른 사실이며 작곡가 이름을 악기 문제에 표시하지 않아 유지 |
| a·b·c·d 정답 패턴 | 원본의 ID 끝 글자는 화면의 보기 번호와 다르다. 게임은 문제·보기 순서를 모두 Fisher–Yates 방식으로 섞고 보기 ID로 채점한다. 검수용 HTML은 원본 순서를 보여 주는 문서이므로 게임 화면 순서로 해석하지 않음 |
| 질문 어조 통일 | 명사형 종결도 뜻이 명확하고 사실 오류가 아니므로 전체 문장을 불필요하게 수정하지 않음 |

같은 주제의 문항을 모두 금지하는 추가 출제 규칙은 도입하지 않았다. 현재의 분야별 3문제·무작위 출제 요구사항을 유지했다.

## 실행한 검사

- 문제 은행 구조·필수 출처·ID·보기·정답 연결 검사: 통과, 오류·경고 0개.
- Vitest 45개: 통과. 이 중 실제 App 컴포넌트를 jsdom에 마운트하는 화면 흐름 테스트는 10개이다.
- 닉네임, 정답·오답, 제출 잠금, 해설·출처, 12문제 완료, 70점 계산, 결과·순위·다시 하기, 기록 재읽기, 삭제 확인·취소, 키보드, 문제 부족, 저장 실패·재시도 검사를 실행했다.
- 로직 테스트에는 200문제 × 보기 순서 24가지 × 선택 4개, 총 19,200가지 채점 경우가 포함된다.
- 전체 HTML 200문제의 질문·보기 ID·정답 ID·정답 텍스트·해설·출처 URL을 실제 JSON과 비교: 일치.
- TypeScript 검사와 Vite 빌드: 통과. 빌드는 500kB 초과 청크에 대한 권고 경고가 있으며 gzip 기준 약 128kB이다.
- Git 등록 대상은 소스·문제·검수 문서·테스트·잠금 파일이다. node_modules·dist·환경 파일은 제외한다.

jsdom 실행은 실제 PC나 모바일 브라우저의 시각적 확인과 다르다. 현재 지정된 control-browser 도구가 없어 적용 중인 Sites 스킬의 “If `$control-browser` is unavailable, skip browser QA” 지시에 따라 실제 브라우저 QA 및 프리뷰 서버 실행은 하지 않았다. Windows 실행, 실제 화면 배치, 브라우저 완전 종료 후 저장 유지는 미실행이다. 직접 확인 절차는 `MANUAL-CHECKLIST.md`를 따른다.

이 상태는 소스를 Git으로 버전 관리하고 사용자 PC에서 최종 실행 확인을 진행할 수 있는 상태이다. 공개 서비스 운영 검증이나 사실 오류의 완전한 부재를 보증하는 의미는 아니다. 외부 공개 배포는 수행하지 않았다. 원격 저장소 URL이 제공되기 전에는 원격 연결·push를 수행할 수 없다.
