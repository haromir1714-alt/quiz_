# 사용자 PC에서 직접 확인할 항목

아래는 실제 브라우저에서의 **미실행 항목**을 확인하는 절차입니다. 자동 DOM 테스트를 통과했다는 사실과 실제 화면 배치·모바일·브라우저 재시작 확인을 구분합니다. README 순서로 실행하고 http://127.0.0.1:5173/ 에 접속해 주세요.

## 기본 흐름

1. 빈 닉네임에서는 시작할 수 없는지, 공백이 제거되는지 확인합니다. 13자 입력 시 시작이 막혀야 합니다.
2. 게임을 시작하고 보기 하나를 고릅니다. 제출 전에는 바꿀 수 있고 제출 전 선택이 없으면 제출 버튼이 비활성화되어야 합니다.
3. 정답과 오답을 각각 선택해 정답/오답 텍스트, 올바른 정답, 해설, 출처가 나오는지 확인합니다. 모든 보기는 제출 후 바꿀 수 없어야 합니다.
4. 출처 링크를 누르면 해당 문제의 공식 자료가 새 창으로 열리는지 확인합니다. 외부 원문은 변경·차단될 수 있습니다. 앱 화면의 링크 연결은 자동 테스트에서 표본 확인했지만 브라우저에서의 외부 사이트 열기는 미실행입니다.
5. 제출·다음 버튼을 연속 클릭해 점수가 중복 반영되거나 문제가 건너뛰지 않는지 확인합니다.
6. 12문제를 마친 후 결과 보기를 누릅니다. 총점은 정답 수×10, 분야별 분모는 각 3, 총 분모는 12여야 합니다. 같은 버전의 기록이 있으면 점수 기준 순위가 나옵니다.
7. 전체 순위 보기에서 닉네임·점수·일시를 확인하고 결과로 돌아갔다가 다시 순위에 가도 기록이 한 개만 추가되어야 합니다.
8. 다시 하기로 시작 화면에 돌아갈 수 있어야 합니다.

## 브라우저 기록 유지·삭제

1. 게임을 완료해 저장 성공 메시지를 확인합니다. 새로고침한 뒤 순위를 열어 기록이 남아 있는지 확인합니다.
2. 브라우저를 완전히 종료합니다. 필요하면 로컬 서버를 다시 켠 뒤 같은 브라우저·프로필에서 **같은 주소**로 열어 기록을 확인합니다. 실제 브라우저 재시작은 여기서 직접 확인해야 합니다.
3. 순위 화면에서 모든 완료 기록 삭제를 누른 뒤 취소합니다. 기록이 남아 있어야 합니다. Escape도 취소로 동작해야 합니다.
4. 다시 삭제를 눌러 확인하면 이 앱의 기록만 지워져야 합니다. 실제 기록이 있다면 삭제되는 작업이므로 시험 기록으로 확인합니다.

## 키보드·모바일·시각적 확인

- Tab/Shift+Tab으로 모든 입력과 버튼에 접근합니다. 보기에서는 방향키 또는 Space로 선택하고 제출 버튼에서 Enter를 누릅니다. 선택 상태·포커스가 보여야 합니다.
- 채점 후 피드백, 새 문제에서는 제목으로 포커스가 옮겨져야 합니다. 삭제 창에서는 포커스가 창 내부에서 순환하고 Escape로 닫혀야 합니다.
- Chrome/Edge에서 F12를 누르고 기기 도구 모음(Ctrl+Shift+M)을 켠 뒤 폭 360px, 390px, 768px에서 확인합니다. 확대 200%에서도 확인합니다.
- 보기 텍스트가 잘리거나 버튼이 겹치지 않아야 합니다. 순위 표는 좁은 화면에서 표 영역을 가로로 스크롤할 수 있습니다.
- 실제 휴대전화의 터치와 보조 기술은 별도 확인이 필요합니다. 기본 서버는 PC의 127.0.0.1에만 연결되므로 휴대전화에서 같은 주소를 입력해 PC 앱에 접속할 수는 없습니다. 모바일 레이아웃과 실제 원격 접속은 다릅니다. LAN 공유나 공개 배포는 설정하지 않았습니다.

## 오류 안내 — 직접 조작 대신 자동 검사 권장

저장 실패·손상 데이터·문제 부족은 자동 테스트에서 인위적으로 재현했습니다. 정상 기록을 손상시키지 않도록 이 항목은 `npm test`로 확인하는 것을 권장합니다.

- 저장 실패: 저장 쓰기 예외를 주입한 자동 테스트에서 실패 안내·순위 미등록·같은 ID 재시도 후 1회 저장을 확인했습니다.
- 손상 데이터: 테스트용 저장소의 잘못된 JSON을 제외하고 원본과 정상 기록을 보존하는지 확인했습니다.
- 문제 부족: 과학 분야 문제를 뺀 테스트 데이터에서 부족 사유와 시작 비활성화를 확인했습니다. 실제 문제 은행을 지울 필요는 없습니다.

브라우저 정책에 따른 실제 저장 차단·용량 부족의 전체 조합, 스크린리더 음성, 실제 기기 간 브라우저 차이는 미실행입니다.
